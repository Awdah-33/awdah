# رجعة — Frontend

واجهة منصة رجعة (React + TypeScript + Vite).

## المتطلبات

- Node.js 18+
- npm 9+

## التشغيل

```bash
cd frontend
npm install
npm run dev
```

افتح المتصفح على: **http://localhost:5173**

## الصفحات

- تسجيل الدخول (بيانات تجريبية — أي إدخال يعمل)
- لوحة التحكم
- تسجيل غسلة (الشاشة الرئيسية)
- العملاء
- الفواتير
- الولاء
- التقارير
- الإعدادات

## ملاحظات

- Arabic RTL افتراضي
- بيانات Mock فقط — لا يوجد Backend بعد
- CSS بسيط بدون مكتبات UI
